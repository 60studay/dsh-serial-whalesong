## 五、🔴 刚查出来的 bug（未修，未报）

**`serial_web` 的 `openBrowser: false` 是坏的，而且工具描述在骗 AI。**

```js
// tools/web.js:77
if (args?.openBrowser === true) argv.push('--open-browser');
// ← 没有 else，永远不会传 --no-browser
```

```python
# cli.py:658  webctl 的默认值
"--open-browser", dest="open_browser", action="store_true",
default=True   # ← 默认就是开
```

**后果**：
- 不传 `openBrowser` → 不传任何 flag → **默认 True → 浏览器照样弹出**
- `openBrowser: false` 与"不传"走同一条路 → **两个都是弹**

**更危险的是描述**：`web.js` 里写着 `Omit to just return the URL.` —— **这句是假的**。
AI 会照描述做决定，然后每次都弹用户一个窗口。

**修法（5 行）**：
1. `openBrowser === false` 时传 `--no-browser`
2. 不传时也传 `--no-browser`（默认不弹）
3. 改掉那句假描述，写成"**默认不弹；要弹必须显式要**"

**用户的原话**：「默认关闭，需要人工让 AI 唤起界面」。
**侧边网页版（4.9 iframe）不算弹窗口，不受这条限制。**
