# 设计：B4 窄屏 / 侧边栏模式（嵌入 DSH 的前提）

> **代号**：B4 ｜ **目标版本**：v2.3.1（原 1.25「侧边栏可折叠」并入这里）
> **前置**：无（纯前端） ｜ **后接**：E4 侧边栏嵌入

## 一、为什么要先做这个

DSH 右侧栏（Better Sidebar 的 `sidebar.right.pane.tab`）宽度大约 **320~480px**。
我们现在的页面按全屏设计，塞进去会：

- 侧栏设置面板吃掉一半宽度，收发区没地方
- 状态轨道、徽章、时间戳挤成一团
- 输入框和发送按钮换行

**这不是"嵌入之后再修"，是嵌入的前提。** 而且现在做，后面加功能时天然按窄屏设计，不会返工。

## 二、三档布局（按容器宽度，不是按屏幕宽度）

| 档 | 宽度 | 布局 |
|---|---|---|
| **宽** | ≥ 1100px | 现在这样：左收发 + 右设置并排 |
| **中** | 700~1100px | 设置面板**默认收起**，点「⚙ 设置」滑出覆盖层（复用已有折叠按钮） |
| **窄（侧栏）** | 360~700px | **单列**：状态条压成一行摘要 → 收发区占满 → 输入框一行 + 展开按钮；设置面板永远抽屉 |

**技术要点**：用 **CSS 容器查询（`@container`）**，不要只用媒体查询。
理由：以后如果不用 iframe 而是直接嵌成 React 面板，**视口宽度不等于面板宽度**，媒体查询会失效。

## 三、窄屏下的取舍（明确写死，避免临时拍脑袋）

| 元素 | 宽屏 | 窄屏做法 |
|---|---|---|
| 状态轨道 | 多行历史 | **压成一行**：`● 连接正常 · 已发 12 · 500ms`，点开看完整 |
| 徽章 + 时间戳 | 全显示 | 保留徽章，**时间戳只在行尾显示**（省宽度） |
| 侧栏设置 | 常驻 | **抽屉**（已有折叠按钮复用） |
| 输入框 | 多行 | 一行；`Shift+回车` 展开多行 |
| 「读一次 / 清空」 | 一行 | 收进 `⋯` 菜单 |
| 规则面板 | 列表 | 折叠成"N 条规则"，点开 |
| 外观面板 | 面板 | 全屏覆盖层 |

## 四、已实现的可以复用

- `◂ 收起 / ▸ 设置` 折叠按钮**已经有了**（1.25 实际上做了）
- 主题、外观变量已全走 CSS 变量，改断点不动样式本身

## 五、判据（360px 宽下逐条打勾）

- [ ] 无横向滚动条
- [ ] 所有按钮都能点到（含 `⋯` 菜单里的）
- [ ] 收发区至少能显示 3 行完整内容，不被迫换行成竖排
- [ ] 输入一条命令能发出去，回显正常显示
- [ ] 设置抽屉打开后能关上，且不挡住收发区太久（覆盖层，可滑走）
- [ ] 在 480px（DSH 侧栏典型宽度）下，**首页不用滚动就能看到"状态 + 最后一条回显"**

## 六、不做什么

- ❌ 不做手机端专门布局（先解决侧栏宽度，真到手机再说）
- ❌ 不做"响应式重写"——只调断点与折叠策略，不重写组件
- ❌ 不动逻辑层（`app.js` 的数据流不变）
