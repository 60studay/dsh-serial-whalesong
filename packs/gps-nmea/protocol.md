# GPS / 北斗模块（NMEA 0183 输出）

> **状态**：📄 来自 NMEA 0183 标准与常见模块手册，**本机未实测**（`unverified`）
> **来源**：[NMEA 0183 参考手册](http://diec.unizar.es/~mdpelaez/personal/Comunicaciones_satelite/Lassen%20iQ_Reference%20Manual_Rev%20B_April%202005.pdf)

## 特点：**不用发命令，上电就一直说**

和别的设备相反 —— 它不等你问，每秒往外吐 ASCII 行。

```
$GPGGA,123519,4807.038,N,01131.000,E,1,08,0.9,545.4,M,46.9,M,,*47
$GPRMC,123519,A,4807.038,N,01131.000,E,022.4,084.4,230394,003.1,W*6A
```

**所以用我们的工具时**：不要 `send`，直接读。用网页的「读一次」或监视模式看字节流。

## 先确认是不是它

```
上电后 1~2 秒内应收到以 $ 开头的行
期望见到：$GPGGA / $GNGGA / $GPRMC / $GNRMC（G=GPS，N=北斗+GPS）
```

**波特率几乎都是 9600 8N1。**

## 最常看的两个语句

**`$GPGGA` —— 定位质量**

```
$GPGGA,hhmmss.ss,ddmm.mmmm,N,dddmm.mmmm,E,q,ss,h.h,alt,M,geoid,M,,*CS
```
| 字段 | 含义 | 注意 |
|---|---|---|
| 6 | 定位质量 | **0=无效，1=单点，2=差分，4=RTK** |
| 7 | 卫星数 | 冷启动时常常是 0 |
| 8 | HDOP | 越小越准 |

**`$GPRMC` —— 时间/位置/速度**

```
$GPRMC,hhmmss.ss,A,ddmm.mmmm,N,dddmm.mmmm,E,sog,cog,ddmmyy,mv,mvE,mode*CS
```
| 字段 | 含义 |
|---|---|
| 2 | **A=有效，V=无效**（`V` 表示还没定位） |
| 3/5 | 纬度 / 经度，格式 `ddmm.mmmm`（**度分，不是十进制度**） |
| 7 | 地面速度（节） |
| 9 | 日期 `ddmmyy` |

## 坑

1. **`ddmm.mmmm` 是"度分"不是"度"**：`4807.038` = 48°07.038′ = 48.1173°。
   **直接当小数用会算出错误位置。**
2. **校验和**：`*` 后面两位是前面所有字符的 XOR。**严格模式可以校验，日常可以先不看。**
3. **室内几乎定不了位**：`$GPGGA` 的质量位会是 0、`$GPRMC` 是 `V` —— **这不是模块坏**。
4. **冷启动 30~60 秒**才出有效定位。
5. 有的模块**默认只输出部分语句**，可用 `$PCAS03`（中科微）或 `$PMTK314`（联发科）配置 ——
   **不同厂家命令不同，发错没反应是正常的。**

## 用我们的工具怎么玩

```
网页监视模式 → 看连续字节流（不要 send）
或 serial_send(com="COM9", command="")  ← 空命令仅触发一次读取（视版本）
读法卡（C1）以后可以直接解析成经纬度
```
