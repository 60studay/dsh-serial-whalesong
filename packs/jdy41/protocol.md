# JDY-41（2.4G 无线串口模块，**不是蓝牙**）

> **状态**：📄 来自官方手册 V5（`JDY-41手册-V5版本.pdf`），**本机未实测**
> **来源**：本地资料 `E:\资料\模块\JDY-41(2.4G通信)\...\JDY-41-V5版本手册\`
> **一句话**：2.4G 私有协议、160 米、成对使用；**用十六进制指令配置，不是 AT 指令**

## 最容易搞错的三件事

1. **不是蓝牙** —— 手机连不上，必须**两个模块配对使用**（一个发一个收）。
2. **指令是十六进制帧，不是 `AT+...` 文本**。例如读版本是 `AB CD`，不是 `AT+VERSION`。
3. **配置时要把 `CS` 和 `SET` 两个引脚都拉低** —— 这是**硬件引脚**，光发串口命令没用。

> ⚠️ 第 3 条对我们插件是硬限制：**插件只能发字节，不能拉引脚。**
> 所以「配置参数」这一步需要硬件配合（底板跳线 / 按键 / 用 MCU 拉低）。
> 但「透传通信」不需要 —— 透传只要 `CS` 接地、`SET` 悬空。

## 先确认是不是它

```
配置状态（CS=L, SET=L）下发：AB CD      （十六进制！）
期望返回：+V5
```

发 `AT` **不会有任何回应** —— 它不是 AT 模块。

## 引脚（15 脚）

| 脚 | 名称 | 说明 |
|---|---|---|
| 1–8 | GPIO1–GPIO8 | 可配置成输入/输出，也能被远端遥控 |
| 9 | VCC | **2.2–3.6V**（别接 5V） |
| 10 | RXD | TTL 串口输入 |
| 11 | TXD | TTL 串口输出 |
| 12 | **SET** | 配置使能，**低电平有效** |
| 13 | **CS** | 片选（也控制睡眠/接收模式） |
| 14 | GND | 地 |
| 15 | RF | 天线（外置天线版才有） |

### CS / SET 电平表（**背下来，接错就配不了**）

| 用途 | CS | SET |
|---|---|---|
| **配置参数**（波特率/频道/功率/类型/ID） | **L** | **L** |
| 透传（A0 模式） | L | H/悬空 |
| 串口指令控 IO（A0） | L | L |
| 遥控器发射/接收（C0~C7） | H/悬空 | H/悬空 |

## 指令集（全部十六进制，以 `0D 0A` 结尾）

| 指令 | 作用 | 回包 |
|---|---|---|
| `AB E3 0D 0A` | 复位 | `+OK\r\n` |
| `AB CD` | 读版本 | `+V5\r\n` |
| `AA E2 0D 0A` | 读参数 | `AA E2 <8字节参数> 0D 0A` |
| `A9 E1 <参数8字节> 0D 0A` | 写参数 | `+OK` |
| `F2 AD 0D 0A` | 读设备 ID | `F2 AD <ID4> 0D 0A` |
| `F1 AE <ID4> 0D 0A` | 写设备 ID（写 0 恢复出厂 ID） | `+OK` |
| `B1 CA <目标ID4> <数据> 0D 0A` | 指定地址发数据（V5 最多 **20 字节**；目标 `FF FF FF FF` = 广播） | 视配置 |

### 写参数的 8 个字节（`A9 E1` 后面）

```
例子：A9 E1 04 00 09 A0 66 77 88 99 00 05 0D 0A
        └┬┘ └┤ └┤ └┤ └┬┘ └────┬────┘ └┤ └┤
        头  波特率 频道 功率 CLSS   无线ID    ACK 备用
```

| 字节 | 含义 | 取值 |
|---|---|---|
| 波特率 | 1=1200 2=2400 3=4800 **4=9600** 5=19200 6=38400 | 出厂 **4（9600）** |
| 频道 | 0–127 | 默认 0 |
| 功率 | 0=135db? 1=-25 2=-15 3=-5 4=0 5=+3 6=+6 7=+9 8=+10 **9=+12db** | 默认 9 |
| CLSS | **A0=透传**、C0/C1=遥控发射、C2–C4=接收、C5–C7=学习型接收 | 默认 A0 |
| 无线 ID | 4 字节，**收发双方必须一致** | 出厂唯一流水号 |
| ACK | 0=无应答 1=有应答 | 默认 0 |

## 坑

1. **两边的「频道」和「无线 ID」必须一致**，否则收不到 —— 这是最常见的“配对不上”。
2. **不知道对方 ID 就广播**：目标填 `FF FF FF FF`。
3. **V5 之前指定地址通信只有 5 字节**，V5 提到 20 字节 —— 固件版本不对会截断。
4. **配置必须 CS+SET 都拉低**；透传必须 CS 接地、SET 悬空。**接错的现象是“发什么都没反应”。**
5. GPIO 控制指令 `B1 CA <ID4> E7 FF 3F` 这种，`E7` 是控制命令头，后两个字节是 GPIO 掩码。
6. **和 JDY-40 引脚兼容但协议不同**，别混用指令。

## 用我们的工具怎么玩

**透传阶段**（CS 接地、SET 悬空）：

```
serial_send(com="COM7", command="hello", hold=true)   ← 直接发文本，对面模块串口会收到 hello
```

**配置阶段**（CS+SET 都拉低，需要硬件配合）：

```
发十六进制：AB CD                       ← 读版本
发十六进制：A9 E1 04 00 09 A0 66778899 00 05 0D 0A   ← 设 9600/频道0/功率9/透传/ID
```

> 我们的工具能不能发十六进制：看 `serial_info` 里的 newline 与发送模式；
> 网页端把「显示模式」切到**十六进制**就能按 hex 输入发送。
